# Tsumugi Life Works App Support Site

This folder contains a minimal static site for App Store submission.

Files:
- `index.html` — support page
- `privacy.html` — privacy policy for 我慢貯金

Recommended publishing method:
1. Create a public GitHub repository such as `tsumugi-life-works-site`.
2. Upload `index.html` and `privacy.html` to the repository root.
3. In GitHub: Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the default branch and `/ (root)`, then Save.
6. After deployment, confirm both pages open publicly over HTTPS.

Typical URLs will look like:
- Support: `https://<GitHub-user>.github.io/tsumugi-life-works-site/`
- Privacy: `https://<GitHub-user>.github.io/tsumugi-life-works-site/privacy.html`

Do not put private information such as a home address into these files unless you have separately determined it is legally required for your distribution model.
